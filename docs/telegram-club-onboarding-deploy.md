# Telegram club onboarding deployment

This release includes the Telegram bot onboarding flow that requires a user to register a club before accessing the bot menu.

The change was merged into `refactor/unified-telegram-worker` in commit `ee9000e2102bf94e32f8f3a7e977f5b7b981c9cc`.

This documentation-only commit is intended to trigger the configured staging deployment workflow from the default branch. It does not change application behavior.
