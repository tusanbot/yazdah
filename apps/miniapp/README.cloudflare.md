# Mini App on Cloudflare

This is a Next.js app, not the game's scheduled worker. The Cloudflare build output is generated by OpenNext; install and lock the compatible `@opennextjs/cloudflare` dependency, then run its build before deploying this config. Do not deploy until the build output exists and a staging API URL is configured in the Mini App environment.

The requested `football-empire-web-staging` Worker is currently assigned to the scheduled game processor in `apps/worker/wrangler.toml`. Do not also use that same Worker name for the Mini App; Cloudflare Worker names must be unique. This naming conflict needs a decision before deploying either service.
